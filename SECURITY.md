# Security policy

## Supported versions

Security fixes are made against the latest version on the default branch.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's
private vulnerability reporting feature for this repository, if enabled. If it
is unavailable, contact the repository maintainers privately using the
security contact listed in the repository's GitHub profile. Include the
affected version, impact, and steps to reproduce. Please allow maintainers
reasonable time to investigate and coordinate a fix before public disclosure.

nodecheck is designed to collect local system metadata using read-only
queries. It does not install updates, change configuration, or contact a
remote service. Treat generated reports as potentially sensitive host
information and share them only with intended recipients.
